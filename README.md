# regiss.me 💜

Meu portfólio pessoal: um espaço para reunir projetos, experiências e alguns detalhes que têm a minha personalidade.

🌐 **Acesse:** [regiss.me](https://regiss.me)

## Sobre o projeto

O site foi desenvolvido para apresentar meus projetos e minhas redes de uma forma leve, interativa e com identidade própria. A página inicial traz elementos inspirados no Garfield, menus flutuantes em formato de patinhas, animações e pequenos easter eggs.

## Projetos

- **[Follow Tracker](https://regiss.me/followtracker/)** — projeto para acompanhar e comparar listas de seguidores e pessoas que você segue no Instagram.
- **[Quotes](https://regiss.me/quotes/)** — espaço de frases e citações, com uma experiência visual própria.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- [GSAP](https://gsap.com/) para animações
- Google Fonts

## Estrutura

```text
/
├── index.html       # Página inicial do portfólio
├── style.css        # Estilos da página
├── script.js        # Interações e animações
├── followtracker/   # Página do projeto Follow Tracker
└── quotes/          # Página do projeto Quotes
```

## Publicação

O site é hospedado pelo **GitHub Pages** e utiliza o domínio personalizado [regiss.me](https://regiss.me).

As atualizações são publicadas pelo repositório: basta enviar as alterações (commit e push) para a branch configurada no GitHub Pages.
